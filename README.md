# Diebaties-tool
A Machine Learning-based Diabetes Risk Prediction Tool that analyzes health parameters to predict diabetes risk using Python and Scikit-learn.
🩺 Diabetes Risk Prediction Tool

📌 Project Overview

The Diabetes Risk Prediction Tool is a Machine Learning-based healthcare application that predicts the likelihood of diabetes based on various medical parameters.

Users can enter health-related information, and the trained ML model analyzes the data to generate a diabetes risk prediction.

🚀 Features

- User-friendly web interface
- Diabetes risk prediction
- Machine Learning integration
- Medical parameter-based analysis
- Instant prediction results

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib

📊 Input Parameters

- Pregnancies
- Glucose
- Blood Pressure
- Skin Thickness
- Insulin
- BMI
- Diabetes Pedigree Function
- Age

⚙️ Installation

Clone the repository:

git clone YOUR_REPOSITORY_URL

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py

🎯 Project Objective

To demonstrate the application of Machine Learning in healthcare by developing a tool for preliminary diabetes risk assessment.
